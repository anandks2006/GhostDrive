    Irreversible
    Factory reset
    
      
    
        This erases your vault permanently.
        
      
          
    • Master key, keystore, and encrypted index are deleted.
      • 
          
    • All locally stored file ciphertext is deleted.
      • 
          
    • Backend credentials are removed from the OS keyring.
      • 
          
    • Files stored on remote backends become permanently unrecoverable.
      • 
        
    
        There is no undo. If you have your recovery phrase, use “Restore from recovery phrase” instead.
